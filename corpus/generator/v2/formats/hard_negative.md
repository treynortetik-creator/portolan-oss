# Internal note

An internal note or message thread written by the vendor's staff that sounds like account news but contains no real fact about the customer. It carries only the near-miss statements in the script.

## Output format

- Plain text. Paragraphs separated by blank lines.
- No headings, no bullet symbols.

## Realism

- Reads like an ordinary internal note: context, chatter, the near-miss statements, a sign-off.
- Everything outside the near-miss statements is allowed color: process talk, scheduling, generic industry talk with no account-specific claim.
