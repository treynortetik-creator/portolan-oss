# Chat channel day

One day of messages in a shared Slack or Teams channel between the customer's staff and the vendor's staff.

## Output format

- One message per line, in this exact shape: `Full Name: message text`
- Use the exact full names from PEOPLE. Only people listed in PEOPLE post.
- Do not write timestamps, reactions, headings or blank lines. They are added afterwards.
- A message is one line. Never break a message across lines.

## Realism

- Chat is short and informal: fragments, quick replies, questions answered minutes later, people tagging each other by @handle.
- Follow each person's chat style: some use emoji, some write one word, some write a careful paragraph.
- Allowed color: good mornings, quick where-is-it answers, thanks, lunch and weather chatter. No plans, promises or times.
